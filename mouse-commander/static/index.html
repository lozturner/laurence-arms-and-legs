About your mouse

Redragon MMO mice without the Redragon software installed will typically emit their extra buttons as one of:

  • F13–F24 — most common for profile 1 buttons
  • Mouse Button 4 / 5 — the two thumb buttons
  • Media keys — volume, play/pause

MouseCommander listens for all of these simultaneously so nothing is missed.

Actions when Override is active

When Override Active is on, MouseCommander intercepts mapped buttons and executes your configured action instead of whatever would normally happen. Unmapped buttons pass through as normal.
